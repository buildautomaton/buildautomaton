# R2 file store

`r2FileStorePlugin` (service id `file-store`) stores files in one R2 bucket. Same contract as the [disk file store](./file-store.md). Import it from `@buildautomaton/plugins/worker`.

```ts
import { r2FileStorePlugin } from '@buildautomaton/plugins/worker';

r2FileStorePlugin({
  options: { bucket: env.MARKETPLACE_FILES, prefix: 'marketplace', backend: 'r2' },
})
```

`prefix` (or `root`) scopes keys inside the bucket. [Worker host](./worker-host.md) installs this when you pass `r2`.
